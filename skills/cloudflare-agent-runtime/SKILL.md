## 技能用途與觸發時機

cloudflare-agent-runtime：在 Cloudflare Workers 上使用 Agents SDK、Durable Objects、Workers bindings、Wrangler、MCP 等技術，建置與審查生產環境的 AI agent。適用情境包括建立 Cloudflare 托管的 agent、有狀態的聊天、Durable Object 協調、WebSocket 應用、排程的 agent 工作流程、Worker MCP 伺服器，或審查 Cloudflare agent runtime 程式碼；並支援即時狀態管理、可觀測性與安全部署。
