> **公開狀態：個人技能恢復版 metadata-only。** 本檔案保留可觸發的用途描述；原始 atomic skill body 未完整保存在可保留的本機備份中。

## 技能用途與觸發時機

在需要於 React/TypeScript 專案中建立、審核或強制執行 UI 本地化（i18n）流程，或將硬編碼字串轉換為 locale 資源時使用 kimi-localization-toolkit。本工具適用於以 i18next 或 JSON locale 檔為基礎的多語環境，並會特別檢查 en-US 與 zh-CN 的覆蓋情況。
